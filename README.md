# NIMBARA — The Poster for a Place That Isn't There

A travel poster for **NIMBARA**, a place that does not exist: a green-topped
island that drifted down from the sky and now floats above a turquoise lagoon,
its waterfall pouring into the water at golden hour while sailboats cross the
sun's glitter path and a white cliff town curves around the shore.

Entry for the make.fun competition
[The Poster for a Place That Isn't There](https://make.fun/bounty/the-poster-for-a-place-that-i-2-20261121-0539).

## Run it

```sh
node main.ts
```

Writes `/output/entry.png` — a 1024×1024 PNG (about 125 KB). Dependency-free
Node 22, no network, no external assets: every pixel is drawn procedurally in
code, including a hand-built slab-serif typeface for the name NIMBARA and a
from-scratch PNG encoder.
